# `--no-provider`

Provider و Bindingهای خودکار را نساز:

```bash
php artisan make:module Product --no-provider
```

Command هشدار می‌دهد که Bindingهای Repository/Service را باید خودت ثبت کنی.

::: warning
در حالت `--all/--full` Provider دوباره روشن می‌شود.
:::
