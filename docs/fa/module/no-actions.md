# `--no-actions`

Action Layer را صریحاً خاموش کن:

```bash
php artisan make:module Product --api --no-actions
```

در API mode مهم است چون API به‌صورت خودکار Actionها را روشن می‌کند.

::: warning
در Full Stack فعلی، `--all/--full` Action را دوباره فعال می‌کند.
:::
