# سازگاری

Constraintهای فعلی Composer:

| وابستگی | نسخه |
| --- | --- |
| PHP | `^8.1 || ^8.2 || ^8.3 || ^8.4 || ^8.5` |
| Laravel Framework | `^10.0 || ^11.0 || ^12.0 || ^13.0` |
| Composer | 2.x پیشنهاد می‌شود |

پکیج از Package Discovery لاراول استفاده می‌کند و با ساختار استاندارد Application کار می‌کند، در عین حال Base Namespace و مسیر خروجی قابل تغییر است.
