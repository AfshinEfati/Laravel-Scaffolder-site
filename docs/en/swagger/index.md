# OpenAPI / Swagger

Laravel Scaffolder ships two related documentation paths:

1. **Module annotations** generated by `make:module --swagger`.
2. **Standalone JSON + UI** generated with `swagger:generate`, `swagger:init` and `swagger:ui`.

The standalone path does not require L5-Swagger.

```bash
php artisan swagger:init
php artisan swagger:generate --title="My API" --version=1.0.0
php artisan swagger:ui
```

Swagger configuration lives under `module-generator.swagger` and can also be controlled by environment variables.
