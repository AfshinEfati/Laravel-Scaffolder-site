# Laravel Scaffolder Documentation

Official bilingual documentation website for [Laravel Scaffolder](https://github.com/AfshinEfati/Laravel-Scaffolder).

## Local development

```bash
npm install
npm run docs:dev
```

Production build:

```bash
npm run docs:build
npm run docs:preview
```

The site is built with VitePress and published to GitHub Pages from `main`.

Documentation is organized as separate English and Persian pages for installation, every `make:module` option, generated layers, schema discovery, OpenAPI/Swagger tooling, utilities and configuration/reference material.
